# 京东风控避坑指南

> 全部结论来自 2026-09-21 凌晨实战：90 分钟采集 13 个商品后被拦，
> 失败截图逐张复核过。这是这条链路上**最贵的失败模式**，开跑前必读。

---

## 一、风控不是一次触发，是三级升级

| 级别 | 表现 | 性质 | 应对 |
|---|---|---|---|
| 一级 · 前置降级 | 店内结果页「店铺」标签消失；店铺列表里找不到目标店铺；结果页换成简版结构 | 最早信号，登录态还在 | **见到就降速或停手**，别等 |
| 二级 · 正式拦截 | 弹出「京东验证 / 验证一下，购物无忧 / 请点击下方按钮完成安全验证 / [快速验证]」页 | 搜索仍可用，详情页被挡 | **立即熔断整批** |
| 三级 · 不可逆 | 登录态失效，搜索跳 `com.jd.lib.login.feature`；页面「登录后，购物更轻松」；`screencap` 返回 **0 字节**（FLAG_SECURE） | 只能人工重新登录 | 停批，等人 |

实测时间线：01:33 出现二级（验证页），01:59 恶化到三级——**中间只隔 26 分钟**。

> 最贵的误判：验证页没有任何资源 ID 地标，会落进通用 `other` 分支。
> 我们曾因此把 10 个商品连环失败错记成「没进详情页」，连撞 34 分钟没人停手。

---

## 二、风控在看你什么（行为指纹清单）

90 分钟内 ~200 次控件点击（43 次店内搜索 / 40 次规格点选 / 44 次退栈 / 12 次重进店）后被拦。
量并不大，问题全在**形态**：

| 指纹 | 我们的实测 |
|---|---|
| 节奏机械化 | 点击间隔固定 `random(1.2, 3.5)` 秒，200 次点击**无一次超 4 秒**的阅读停顿 |
| 坐标零方差 | 固定像素点一夜被点上百次 |
| ADBKeyboard | `ime set com.android.adbkeyboard` —— 真人手机不可能装的输入法，最强技术指纹 |
| 无障碍树高频 dump | 每次判页/读卡片/读面板各一次，整夜数百次 |
| screencap 高频 | 每 SKU 一张证据 + 每失败一张，~60 次 |
| 同店高频往返 | 12 次「掉出店铺 → 全局搜索 → 进店」，真人不会这么逛 |
| 重复采集 | 13 个商品跑了 21 轮（边跑边修 bug），请求量凭空多 60% |
| 深夜时段 | 00:00–02:00 是风控权重最高窗口 |

## 三、实测失效 vs 现行参数

| 项 | 旧（已作废） | 新（现行） |
|---|---|---|
| 点击间隔 | 1.2–3.5s | **3–9s** |
| 批次休息 | 每 5–8 商品休 65–175s | 每 5 商品**长休 3–8 分钟** |
| 阅读停顿 | 无 | 进详情页前后各 5–10s；商品之间插一次无意义滑动 |
| 重复采集 | 边跑边修 | 同一商品当场只采一轮，修好再重采 |
| 输入法 | ADBKeyboard 常驻 | 系统输入法 + `input text`，用完立刻切回 |
| 时段 | 任意 | **避开 00:00–07:00**，用 9:00–22:00 |
| 放量 | 直接全量 | 先灰度 10 个商品，观察 15 分钟 |

## 四、熔断的实现要点（血泪教训）

1. **风控/登录检测必须在判页之前**。`detect_verify()` 曾挂在「成功进详情页」分支里，
   风控页走失败分支——那段代码**一次都没执行过**。正确顺序：
   点开卡片拿到页面 → **先判是不是验证页/登录页** → 再判业务页型。
2. **判据别只靠资源 ID**。验证页用文案：「快速验证」「购物无忧」「安全验证」；
   登录页用包名 `com.jd.lib.login.feature` + 文案「登录后，购物更轻松」；
   **`screencap` 返回 0 字节（FLAG_SECURE）本身就是可靠熔断信号**。
3. **等待循环必须带熔断出口**。`wait_kind(timeout=25)` 每 0.8s dump 一次树，
   撞墙时会对着验证页白扫 ~31 次（10 个商品 ~310 次）——
   等于主动告诉风控「自动化程序正在试图穿门」，会加速从二级升到三级。
   一旦识别到验证/登录页**立刻返回**，不耗尽 timeout。
4. **熔断 = 整批停，不是单个失败**。落盘「熔断时刻 + 已完成 + 待采」，人工处理完原命令续跑。
5. **「连续 N 个失败暂停 M 分钟」是钝器**：暂停后不查页面状态就继续，4 次暂停全是空等。

## 五、无效手段（已实测，别再试）

**卸载重装 App 不能重置风控。**

- 风控依据是**服务端画像**（账号 + 设备标识 + 行为序列），换客户端不触及任何一项。
- `ANDROID_ID` 在 Android 8+ 按「应用签名 + 用户」派生，卸载重装后**一模一样**
  （实测 `e61f638e690c334c` 前后不变），只有恢复出厂才变。
- 设备序列号、华为 OAID 同样不变（OAID 可在「设置 → 隐私 → 广告与隐私」手动重置，
  这是无 root 下唯一能改的设备级标识）。
- 全新设备首启就会经过 `com.jingdong.app.mall/.bundle.jdrhsdk.JDRiskHandleActivity`
  （京东风控 SDK）——**首启即建档**。

真正有效的组合：**行为侧降速（最根本）+ 换手机号 + 重置 OAID / 换设备**。

---

## 六、保留的好习惯

- **每个 SKU 存一张证据截图** —— 复盘时的铁证全靠它（178KB 纯白验证页 vs 1.5MB 正常详情页，肉眼可辨）。
- **失败时抓现场图**（`_fail/` 目录）。
- **断点续采**：熔断后不用重头来。
- **价格全部从界面树解析**，不引入 OCR/模型猜测的不确定性。
