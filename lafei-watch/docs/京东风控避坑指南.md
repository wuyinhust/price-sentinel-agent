# 京东风控避坑指南

> 结论来源：2026-09-21 实战（90 分钟采集 13 个商品后被拦，失败截图逐张复核）。
> 详细事件记录见 [风控复盘-0921.md](风控复盘-0921.md)。

---

## 〇、避坑前提（先于一切技术细节）

1. **优先使用 iPhone 采集（[zhongerxin/iPhone-use](https://github.com/zhongerxin/iPhone-use)）。**
   iOS 侧京东风控强度低于安卓，且无 ADBKeyboard、uiautomator dump 这类强技术指纹。
   有 iPhone 可用时不走安卓方案。
2. **必须用安卓时，模拟真人是绝对前提，不是调参优化：**
   - 严禁连续点击、高频搜索；
   - 只在人类正常使用京东的时段（9:00–22:00）操作；
   - 用低频率把工作分散到整个项目周期，不追求单日采完；
   - 绝对禁止一口气进行多个高危行为（搜索、进店、SKU 点选连环做）。
3. **熔断纪律：第一次弹出风控页（验证页/滑块）时——**
   1. 立刻停止采集；
   2. 杀掉京东进程（`am force-stop com.jingdong.app.mall`）；
   3. **不要尝试登录、不要试图通过验证**；
   4. 通知用户，等人工决策。

## 一、风控三级升级模型

| 级别 | 表现 | 性质 | 应对 |
|---|---|---|---|
| 一级 · 前置降级 | 结果页「店铺」标签消失、店铺列表缺目标店铺、结果页变简版 | 最早信号，登录态还在 | 见到就降速或停手 |
| 二级 · 正式拦截 | 「京东验证 / 请点击下方按钮完成安全验证 / [快速验证]」页 | 详情页被挡 | 按前提 3 熔断 |
| 三级 · 不可逆 | 登录态失效，跳 `com.jd.lib.login.feature`；`screencap` 返回 0 字节（FLAG_SECURE） | 只能人工重新登录 | 停批，等人 |

实测升级速度：二级 → 三级仅 26 分钟。

注意：验证页无资源 ID 地标，会落进通用 `other` 分支——不专门识别就会把连环撞墙记成普通失败。

## 二、行为指纹清单（风控在看你什么）

| 指纹 | 实测情形 |
|---|---|
| 节奏机械化 | 点击间隔固定 1.2–3.5s，200 次点击无一次超 4 秒阅读停顿 |
| 坐标零方差 | 固定像素点一夜被点上百次 |
| ADBKeyboard | 真人手机不可能装的输入法，最强技术指纹 |
| 无障碍树高频 dump | 每次判页/读卡片/读面板各一次，整夜数百次 |
| screencap 高频 | 每 SKU 一张 + 每失败一张，约 60 次 |
| 同店高频往返 | 90 分钟进出同一家店 12 次，每次 2 个搜索请求 |
| 重复采集 | 13 个商品跑 21 轮（边跑边修 bug），请求量多 60% |
| 深夜时段 | 00:00–02:00 是风控权重最高窗口 |

## 三、采集参数（安卓）

| 项 | 参数 |
|---|---|
| 点击间隔 | 3–9s 随机 |
| 阅读停顿 | 进详情页前后各 5–10s；商品之间插一次无目的滑动 |
| 批次休息 | 每 5 个商品长休 3–8 分钟 |
| 时段 | 9:00–22:00，避开 00:00–07:00 |
| 重复采集 | 同一商品当场只采一轮，修好 bug 再重采 |
| 输入法 | 系统输入法 + `input text`；如用 ADBKeyboard 注入，用完立刻切回 |
| 放量 | 先灰度 10 个商品，观察 15 分钟无异常再放量 |
| 单商品预算 | 点击/重试超上限即放弃该商品并留痕 |

旧参数（点击间隔 1.2–3.5s、每 5–8 商品休 65–175s、ADBKeyboard 常驻、任意时段）已实测失效，勿回退。

## 四、熔断实现要点

1. **检测顺序**：点开卡片拿到页面 → 先判验证页/登录页 → 再判业务页型。检测挂在成功分支里等于没有。
2. **判据**：
   - 验证页文案：「快速验证」「购物无忧」「安全验证」；
   - 登录页：包名 `com.jd.lib.login.feature` + 文案「登录后，购物更轻松」；
   - `screencap` 返回 0 字节（FLAG_SECURE）本身即熔断信号。
3. **等待循环带熔断出口**：识别到验证/登录页立刻返回，不耗尽 timeout。对验证页持续 dump 会加速二级升三级（实测 ~310 次白扫后 26 分钟内升级）。
4. **熔断 = 整批停**，不是单个失败。落盘「熔断时刻 + 已完成 + 待采」，人工处理完原命令续跑。
5. 「连续 N 个失败暂停 M 分钟」是钝器：暂停后不查页面状态就继续，全是空等。

## 五、无效手段

**卸载重装 App 不能重置风控。**

- 风控依据是服务端画像（账号 + 设备标识 + 行为序列），换客户端不触及。
- `ANDROID_ID`（Android 8+）按「应用签名 + 用户」派生，重装后不变，只有恢复出厂才变。
- 设备序列号、OAID 同样不变（OAID 可在「设置 → 隐私 → 广告与隐私」手动重置，是无 root 下唯一能改的设备级标识）。
- 全新安装首启即加载京东风控 SDK（`JDRiskHandleActivity`）——首启即建档。

有效组合：行为侧降速（最根本）+ 换手机号 + 重置 OAID / 换设备。

## 六、应保留的习惯

- 每个 SKU 存一张证据截图（复盘取证全靠它；纯白验证页约 178KB vs 正常详情页约 1.5MB，文件大小本身可辅助判页）。
- 失败时抓现场图（`_fail/` 目录）。
- 断点续采，熔断后不重头来。
- 价格全部从界面树解析，不引入 OCR/模型猜测。
